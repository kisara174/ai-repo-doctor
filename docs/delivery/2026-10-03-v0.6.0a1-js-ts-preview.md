# v0.6.0a1 JS/TS 独立预览交付

交付日期：2026-10-03。**B1–B4 已完成。** [公开预览](https://github.com/kisara174/ai-repo-doctor/releases/tag/v0.6.0a1)已发布，Mac 独立安装与实际调查流程通过。v0.5.2 继续作为稳定 Python 入口。

## 1. 用户得到什么

| 能力 | 预览支持范围 |
| --- | --- |
| overview / symbols | 显式选择 Python、JavaScript、TypeScript，返回统计、限制和真实 ID |
| context | .js/.mjs/.ts 实现源码；target-first、显式 includes、至多 120 行 |
| 文件依赖 | 可唯一定位的本地 ESM import/export 来源；保留歧义 |
| 调用 / impact | 未遮蔽、未改写的顶层直接函数和直达 ESM 实现；反向路径带源码行 |
| map | 同源离线 HTML、JSON、结构 SVG、关系 SVG；搜索完整 ID、展开祖先、文件/符号聚焦 |
| 兼容 | 默认 Python；普通安装不需要 JS extra；旧 Python 地图仍可读 |

Codex 使用工具获取结构与证据，并负责判断和修改。人类页面只呈现结构关系，主流程无需 API Key、无需 Node 分析运行时。

## 2. 这台 Mac 直接使用

无需激活环境或修改 PATH：

```sh
PREVIEW=/Users/kisara/.local/share/ai-repo-doctor/previews/v0.6.0a1/venv/bin/repo-doctor
"$PREVIEW" --version
"$PREVIEW" overview REPO --languages javascript,typescript --json
"$PREVIEW" symbols REPO --languages javascript,typescript --query NAME --json
# REAL_ID 使用上一步实际返回的值
"$PREVIEW" context REPO REAL_ID --languages javascript,typescript --max-lines 120 --json
"$PREVIEW" impact REPO REAL_ID --languages javascript,typescript --depth 2 --json
"$PREVIEW" map REPO --languages javascript,typescript --out NEW_MAP
```

版本输出为 repo-doctor 0.6.0a1。混合仓库可明确选择 --languages python,javascript,typescript；输出目录须尚不存在。

可直接复制给 Codex：

独立 Skill 已导出到 /Users/kisara/.local/share/ai-repo-doctor/previews/v0.6.0a1/skill/SKILL.md，没有自动注册。已安装的稳定 Skill 保留。

## 3. 其他机器安装

需要 Python 3.11+：

```sh
python3 -m venv .venv-preview
.venv-preview/bin/python -m pip install 'ai-repo-doctor[js] @ https://github.com/kisara174/ai-repo-doctor/releases/download/v0.6.0a1/ai_repo_doctor-0.6.0a1-py3-none-any.whl'
```

去掉 [js] 即为无可选后端的 Python 安装；显式请求 JS/TS 时会退出 2 并给出安装提示。
