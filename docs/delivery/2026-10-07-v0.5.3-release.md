## 可用的产品流程

1. Codex 使用 `overview` 查看组成，用 `symbols` 找真实 ID，再用 `context` 获取有界源码及调用证据、`impact` 查看已解析影响。
2. 人使用 `map` 生成离线交互 HTML、`map.json`、`structure.svg` 和 `relations.svg`；可搜索、展开、筛选、聚焦、缩放和导出当前视图 SVG。
3. 按需创建 case、导入带源码引用的调查、重开记录。显式检查及评审关联可保留修复前后的证据；问题判断和代码修改由 Codex 完成。

主要流程无需 API Key。静态调查及地图生成不执行目标仓库代码；只有显式 `verify`/`reproduce` 才执行指定命令。

本版包含调用解析查找表复用、完整 ID 地图搜索、被省略关系数量提示，以及搜索后切换结构树保留选择和祖先路径。保持 Python 3.11+、无运行依赖、节点 200/边 500 上限与旧案件兼容边界。

## 安装及使用

```sh
python3 -m venv .venv
.venv/bin/python -m pip install 'https://github.com/kisara174/ai-repo-doctor/releases/download/v0.5.3/ai_repo_doctor-0.5.3-py3-none-any.whl'
.venv/bin/repo-doctor --version
.venv/bin/repo-doctor overview /path/to/python-repo --json
.venv/bin/repo-doctor symbols /path/to/python-repo --query NAME --json
# 使用 symbols 实际返回的 ID
.venv/bin/repo-doctor context /path/to/python-repo 'FILE.py::SYMBOL' --json
.venv/bin/repo-doctor impact /path/to/python-repo 'FILE.py::SYMBOL' --depth 2 --json
.venv/bin/repo-doctor map /path/to/python-repo --out ./new-repo-map
```

打开 `new-repo-map/map.html` 查阅；SVG 同目录。导出目录应尚不存在。已有 repo-doctor Skill 可继续使用；首次安装的 Skill 用 `skill export --out NEW_SKILL_DIRECTORY` 导出，不能覆盖已有目录。详细调查步骤见 [Codex 调查教程](../CODEX_AND_MAP.md)。

本机持久环境：`/Users/kisara/.local/share/ai-repo-doctor/venv`；普通终端直接调用 `repo-doctor`，无需每次激活。已有 Key 配置保持不变，本轮未读取或调用 API。
