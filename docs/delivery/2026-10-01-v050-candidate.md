## 1. 本轮交付

| 使用者 | 实际可用能力 |
| --- | --- |
| Codex | `overview --json` 获取有界结构概览；已有符号检索、上下文和影响分析；保存带来源指纹的上下文快照；离线导入、校验和保存 Codex 发现；区分 Codex 与人的复核记录 |
| 人 | `map` 生成离线交互 HTML、结构 SVG 和关系 SVG；默认显示可展开的结构总览；搜索文件和符号，切换关系视图、聚焦相邻文件或符号、筛选测试与关系、缩放和平移、导出当前图 |
| 安装 | 无运行时第三方依赖的 Python wheel；安装包内包含页面资源和可导出 Codex Skill；原有 Mac 命令入口继续可用 |

页面只显示项目结构和关系。详细解释、缺陷判断、方案和代码修改交给 Codex；Repo Doctor 负责数据、来源校验和显式检查记录。新的主要路径不需要 API Key，不调用 DeepSeek。使用方法见[操作指南](../CODEX_AND_MAP.md)。

地图数据保留目录、文件、符号、导入、已解析调用、重导出和注册关系。非 Python 文件只读取路径元数据；页面不嵌入完整源码。静态覆盖不足、解析失败和省略节点都有说明，不能据此判定 bug 或承诺运行时调用完整。

受控修复材料是已知缺陷样例，不能作为自主发现能力或诊断准确率证据。一次检查通过也不代表整仓无缺陷。DOM 检查验证脚本行为，不替代 Safari/Chrome 的原生布局和下载检查。

本轮只针对实际阻塞修复：默认测试过滤、收起父节点时仍出现后代、SVG 序列化重复 `xmlns`、快照创建与导入的预算边界不一致，以及点击文件后丢失聚合调用关系。静态全仓关系图较拥挤，因此默认改为收起的结构概览，详细关系按目标查看。

## 4. 正式发布前剩余工作

1. 在允许操作的 Safari/Chrome 中直接打开最终 `map.html`，核对可读布局、展开、搜索、关系筛选、缩放和平移。
2. 用原生下载动作保存当前图 SVG，再独立打开下载文件，核对图形与来源。
3. 新 Codex 会话显式调用 `$repo-doctor`；另记自然语言是否触发隐式匹配。不能将当前会话手动读取 Skill 或执行命令当作新会话隐式触发证据。
4. 前述功能提交的远程 CI 已通过；待上述交付条件满足后，按实际发行提交核对 CI、安装包和版本，再进行正式版本整合与发布。

本次 Codex 浏览器拒绝 `file://` 导航，因而没有完成原生离线打开和下载检查。保留候选状态，不绕过该限制，也不声称已完成全部 P4–P6。后续只完成这些交付检查和由它们证实的阻塞修复；不追加新模型评估、MCP、多语言或自动补丁功能。
