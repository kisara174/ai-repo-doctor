## 最终使用链

安装固定版本 → Codex 加载绑定 Skill → 概览 → 找到真实符号 → 提取上下文与影响证据 → 人类查看结构图/SVG → 安全升级或回滚。

Codex 负责判断和修复。工具提供静态证据和关系图，不扩展自动修复、新语言或收费系统。

## 执行纪律

1. 先完成 V0，再按表推进。只在证据通过后更新状态，不以“代码已写”代替交付。
2. 主代理负责计划、判断、调试、评审及发布。Luna 仅执行符合 AGENTS 规则的明确机械任务；当前规划工作不委派。
3. 每阶段只做用于证明该阶段结果的验证。代码有变化才按影响追加验证；不重复跑 200 仓库以凑数量。
4. 新发现先记录、复现、定位，再修复和复核；不盲目增加接口。
5. 保留现有未提交文件、旧安装、用户 Skill 和历史证据。任何修复都在隔离工作树实施。
6. 不在每阶段重新索要已经取得的授权。遇到真正缺少的输入或无法恢复的阻塞再说明。
