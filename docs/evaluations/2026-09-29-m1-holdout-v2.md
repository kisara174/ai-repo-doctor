## Request and review contract

- One arm, one call per case: six calls maximum. Use `deepseek-flash`, the
  product prompt and `chat-json` transport, explicit disabled thinking, 120
  source lines, 4,096 maximum output tokens, and the existing 64-KiB context
  and 256-KiB wire limits.
- Prepare from a clean committed analyzer checkout. Record its commit, plan
  hash, each context and request hash, provider model, usage, and elapsed time.
  The runner must verify all clean pinned checkouts before dispatch.
- Send through the evaluator's explicit `--allow-network` path. No retries,
  provider fallback, prompt change, additional context, or sample replacement
  after seeing results. A provider or parse failure stops the sequence.
  Report attempted, failed, and unattempted calls separately.
- Manually review every accepted and rejected finding against the pinned
  source, upstream repair, and regression test. A quotation proves provenance
  only. Mark TP, FP, uncertain, or duplicate with a concrete source rationale
  before scoring. A TP requires the known trigger and wrong outcome on a bug
  snapshot; only an accepted TP counts as a useful product issue.

## Decision gate and cost

This small cohort meets the usefulness gate only if all six calls return
parseable responses, at least two of the three known defects yield an accepted
TP, and no fixed snapshot has an accepted false alarm. Report the observed
invalid-response fraction and accepted TP/fixed-FP counts even after an early
stop. A pass justifies a broader independent cohort, not general accuracy or
unattended-use claims. A failure does not undo the working human-reviewed CLI
workflow.

Report provider input/output tokens and an estimated **upper bound** on USD
cost per accepted TP. Price every input token as a cache miss and every output
token at the peak `deepseek-flash` rates of $0.30 and $1.20 per million tokens,
respectively, from the [official pricing table](https://api-docs.deepseek.com/quick_start/pricing/)
checked 2026-09-29. Divide total estimated run cost by accepted TP count;
if no TP is accepted or usage is missing, mark it undefined. This is not a
billing statement: the evaluator does not retain cache hit/miss token counts.
