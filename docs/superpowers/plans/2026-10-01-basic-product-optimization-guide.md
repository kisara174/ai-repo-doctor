## 一、唯一产品目标

**交付一个可 pip 安装、在 Mac 上稳定运行的 Python 仓库结构与证据工具：Codex 能按需调用它理解仓库、定位源码并判断改动影响；人能通过离线交互 HTML 与 SVG 直观查看项目组成和关系。**

Repo Doctor 提供结构、上下文、来源校验和必要的调查记录。Codex 负责详细判断、解决方案和代码修改。主要使用路径不依赖 DeepSeek API Key。

基础版应当把这条流程走完整：

```text
安装 CLI / 加载 Skill
  → 给出本地 Python 仓库路径
  → Codex 读取概览、选择真实符号、取得有界源码与影响证据
  → 人查看结构关系图，搜索、展开、定位、导出 SVG
  → 有具体发现时保存来源明确的调查记录
  → Codex 按授权修改，记录与问题相关的检查
  → 重开报告和图，得到清楚的状态
```

结构问答不必创建 issue。静态调用未解析、没有某条边或存在导入环，不能直接当作 bug。
